# Strike AI

**Strike AI** is a portfolio project exploring private, offline generative AI on Android. The app is designed around running a local language model on-device so users can interact with an AI assistant without relying entirely on a cloud API.

## Project Overview

Strike AI was built to explore the practical side of AI application development beyond prompting alone. The project combines Android development, local LLM integration, conversational UI design, debugging, performance tuning, and voice-feature experimentation.

## Key Features

- Local AI chat experience
- Offline-first architecture
- On-device language model integration
- Mobile conversational interface
- Privacy-focused design with reduced cloud dependence
- Voice recognition and local text-to-speech experimentation

## Technologies & Concepts

- Kotlin
- Android Studio
- Local large language models (LLMs)
- Gemma-family models
- On-device inference
- Mobile UI/UX
- Speech recognition and text-to-speech
- AI application debugging and optimization

## What I Learned

Building Strike AI has given me hands-on experience with integrating an LLM into a real application, debugging model responses, improving conversation handling, understanding local-vs-cloud AI tradeoffs, and optimizing AI performance on mobile hardware.
